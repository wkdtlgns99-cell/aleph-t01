## 2. 짧은 확인 방법 4줄 (T01-C25 형식 엄수)

1. **① 어디로 가나요**: 공개된 배포 주소의 첫 화면(최상단)으로 진입합니다.
2. **② 3단계 이내 무엇을 하나요**: 
   - 1단계: 브라우저 진입 후 첫 화면에서 대상/목적 1문장과 3개 강점 카드를 확인합니다.
   - 2단계: 키보드 `Tab` 키로 첫 번째 카드의 `[근거 메모 보기]` 버튼으로 이동합니다.
   - 3단계: `Enter` 또는 `Space` 키를 눌러 근거 메모를 펼치고, 우측 상단 `[라이트/다크 모드]` 버튼을 눌러 테마를 전환합니다.
3. **③ 무엇이 보이면 통과인가요**: 
   - 1366×768 및 1920×1080 해상도에서 스크롤 전 첫 화면에 소개, 3개 활동 카드, 근거 메모 버튼이 한눈에 보입니다.
   - 선명한 고대비 포커스 링(파란색 아웃라인)이 표시되며, 버튼을 누르면 숨겨져 있던 구체적 근거 문장이 즉시 펼쳐집니다.
4. **④ 안 될 때 무엇이 보이나요**: 
   - 첫 화면에서 내용이 잘려 스크롤을 내려야만 활동 카드가 보이거나, 키보드 이동 시 포커스 링이 보이지 않거나, 버튼을 눌러도 반응이 없거나, 콘솔에 빨간 에러 메시지가 출력됩니다.

## 3. AI와 나의 판단 3줄 (T01-C26 형식 엄수)

1. **① AI에게 맡긴 일**: 
   - 시맨틱 HTML5 구조화, CSS Flexbox/Grid 기반 반응형 레이아웃 설계, WCAG 4.5:1 이상 고대비 테마 변수 구축 및 키보드 접근성(ARIA) 로직 작성을 맡겼습니다.
2. **② 학생이 직접 판단한 일**: 
   - 페이지 대상(협업할 동료)과 목적을 담은 단일 문장 정립, 본인의 실제 핵심 역량(진지함과 긍정성, 39회 리추얼 실행력, 캡스톤 협업) 기반 STAR 문장 및 증빙 근거 선정, 공개할 정보 3종과 비공개할 정보 3종의 원칙과 사유를 직접 결정했습니다.
3. **③ AI 제안을 따르지 않은 일 (이유 포함)**: 
   - AI가 초기에 제안했던 '서윤'이라는 임의의 가상 페르소나 및 화려하지만 접근성을 저해하는 3D 회전 그래픽/형광 원색 배경/무거운 외부 라이브러리를 전면 배제했습니다. 무로그인 즉시 로딩, 1366×768 첫 화면 가시성(T01-C10), 웹 접근성 표준 준수를 위해 순수 바닐라 웹 기술과 정갈한 테크 미니멀리즘 디자인을 채택했습니다.

## 4. 검사에서 발견한 실제 결함 3개 수정 전후 (T01-C17)

### 결함 1: 1366×768 해상도 첫 화면 가시성 탈락 결함 (T01-C10)
- **수정 전 상태**: 상단 히어로 섹션의 세로 높이가 700px를 초과하여, 1366×768 화면에서 스크롤을 내리지 않으면 소개 아래의 활동/근거 카드가 화면 밖으로 완전히 잘려 보이지 않았음.
- **수정 후 상태**: 헤더와 히어로 섹션의 세로 패딩 및 폰트 크기를 유동적으로 최적화하고 콤팩트 3열 그리드를 구성하여, 1366×768 및 1920×1080 해상도의 첫 화면(스크롤 0px)에서 소개, 3개 활동 카드, 근거 메모 버튼이 한눈에 모두 보이도록 개선 완료.

### 결함 2: 키보드 포커스 링 명암비 미달 결함 (T01-C16, T01-C21)
- **수정 전 상태**: 밝은 카드 배경 위에서 흰색 포커스 링(`outline: 3px solid #fff`)을 적용하여, 키보드 Tab 조작 시 포커스가 배경에 묻혀 명암비 1.2:1로 식별이 불가능했음.
- **수정 후 상태**: 다크 모드(`outline: 3px solid #38bdf8`) 및 라이트 모드(`outline: 3px solid #0284c7`)에 각각 7:1 이상의 고대비 포커스 링을 지정하고 2px 오프셋을 주어 키보드 초점이 명확히 보이도록 수정 완료.

### 결함 3: T01-C03 대상 및 목적 1문장 누락 및 가상 페르소나 결함 (T01-C03)
- **수정 전 상태**: 본인(장시훈)이 아닌 가상 인물 '서윤'의 모호한 감성 문구만 배치되어 있어, 누구에게 무엇을 보여주는지 명시된 한 문장이 존재하지 않았음.
- **수정 후 상태**: 히어로 섹션 상단에 `"이 페이지는 함께 협업할 동료에게 저(장시훈)의 강점과 협업 가치관, 그리고 데이터 공개 원칙을 투명하게 공유하기 위한 한 페이지 소개입니다."`라는 명확한 단일 문장 카드를 신설하여 통과 기준을 직관적으로 충족함.
